# 📊 Sales Data Analysis Project

## 📌 Description

This project focuses on cleaning and analyzing sales data using Excel and Power Query.
The goal is to prepare the dataset, extract insights, and understand sales trends over time.

---

## 🛠 Tools Used

* Excel
* Power Query
* Pivot Tables
* Charts

---

## ⚙️ Data Cleaning Process

* Imported data into Power Query
* Removed duplicate records
* Fixed data types (Quantity, Unit Price, Total Price)
* Standardized decimal values
* Recalculated Total Price (Quantity × Unit Price)
* Validated data consistency

---

## 📊 Data Analysis

* Created Pivot Tables
* Calculated statistics (Mean, Median, Mode)
* Analyzed data distribution
* Built sales trend chart (2023–2025)

---

## 📈 Key Insights

* Sales data contains high variability
* Presence of outliers affecting average
* Sales show a declining trend over time
* Data is positively skewed

---

## ▶️ How to Run

1. Open the Excel file
2. Go to Data tab → Power Query
3. Load data using "From Table/Range"
4. Apply cleaning steps
5. Load cleaned data back to Excel
6. Open Pivot Table sheet
7. Explore charts and insights
